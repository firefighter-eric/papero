# Papero 阅读界面

设计目标是安静的论文阅读桌面：左侧论文库与目录、顶部论文信息、正文中英对照。白色阅读纸面与浅灰背景、细分隔线、中性灰强调色、衬线论文标题和正文构成基本视觉语言。品牌使用开放书本轮廓和小写 `papero`。

## 参考图与实现

设计参考图展示 1536px 宽桌面：约 282px 侧栏，51px 英文论文标题，中文副标题，段落式双语正文和底部阅读进度。实现保持该层级、色彩与空间关系。

有意采用的差异：

- 使用 arXiv HTML 的完整正文、实际八位作者、原版摘要以及全部目录。参考图的摘要是示意性改写，不能取代来源论文。
- 原始论文授权说明、作者贡献、联系方式与附录保留在正文；首次打开从摘要开始，论文信息可从目录进入。
- arXiv 的摘要标题虽然使用 `h6`，在阅读界面与一级章节使用相同标题字号；目录缩进最多两级，保持可读性。
- 未生成的中文段落明确标注并展示英文原文，不使用编造译文。论文标题和目录标题从数据获取。
- 正文区域分别滚动。同步模式按对应 block ID 与该段的相对位置对齐，而非整页滚动百分比；交换、切换语言、字号调整与窗口尺寸变化保持当前阅读位置。
- 桌面阅读栏高度根据可用视口计算；参考图中未显示的完整论文表格、公式、参考文献、图像、嵌入链接均保留。

## 交互与适配

论文库支持标题、作者、年份、arXiv 编号与标签搜索，并提供模型系列、研究阶段两项组合筛选。系列标签显示在论文卡片与标题下；同时覆盖预训练、后训练的报告可以被任一阶段匹配，搜索“千问”匹配 Qwen。分类由独立的阅读元数据维护，依据见 [论文标签](paper-tags.md)。点击另一论文取消旧请求，重新加载对应数据。目录跳转同时调整可见语言栏，论文内引用在对应栏定位到原始锚点。

双栏默认中文左侧、英文右侧，可交换或仅显示一个语言。同步滚动可关闭。正文字号为 15–25px，偏好和各论文的 block 阅读位置保存至 localStorage；存储被禁用时继续正常阅读。

同步滚动为双向：鼠标滚轮、触摸、键盘以及直接拖动任意一侧滚动条，都会让另一侧跟随同一段落位置。macOS 自动隐藏的平台滚动条无法保证可发现性，因此桌面使用持续显示的 10px 细滚动轨控制原生正文滚动。轨道支持拖动、点击、方向键、Page Up/Down 与 Home/End，提供 `scrollbar` 语义与百分比读屏状态。移动端继续直接触摸滚动正文。程序驱动的跟随事件被过滤，防止两侧反馈抖动；锚点在输入时立即记录，再按动画帧更新另一栏，避免快速拖动、切换语言或重排时覆盖最新位置。

顶部提供白色、黑色与 Anthropic 风格浅橙三种阅读主题，颜色覆盖整页背景、正文、目录、工具栏、表格、提示、焦点和滚动条。主题保存在原有偏好中；选择器采用 radio group，支持方向键、Home/End 与读屏状态。白色和黑色采用接近 ChatGPT 的中性灰单色配色，浅橙使用暖纸面和陶土色强调。论文原图保持来源颜色。

署名数量或文本过长时，标题下预览最多两行，并提供“查看全部署名”的原生可展开面板，兼容作者、团队与机构的混合署名。完整名单可滚动查看及键盘访问，面板不会把正文阅读区域挤出视口。

760px 以下，侧栏改为可关闭抽屉，首次阅读默认中文单栏。用户选择双语时以垂直两栏显示，保留独立与同步滚动，避免正文横向挤压。表格、长公式和代码示例可以在块内横向滚动，代码可键盘聚焦并保留原始换行与内容，页面整体没有横向滚动。抽屉支持 Escape 关闭和焦点循环。

所有工具栏控件具有语义标签与状态；移动端主要触控目标约 40–44px。加载、无数据、网络或校验失败分别显示状态与重试入口。准备数据的终端命令仅出现在空论文库的设置界面，正常阅读不显示模型配置。

## 数据边界

前端只通过 `loadCatalog`、`loadPaper` 读取数据，不内置论文文本；两种语言的 HTML 都经过同一清洗策略，源 DOM ID 使用语言前缀防止重复。图像地址按数据文件路径解析，支持本地开发或独立对象存储/CDN。导入与翻译由离线脚本完成。

显示时移除 MathML 的 `annotation` 与 `annotation-xml` 完整子树，防止清洗器解包隐藏的 LaTeX 或 HTML 注释后产生第二行重复公式。可见 MathML、公式原始 `alttext`、编号和论文数据中的完整公式均保留。

用户批准的 Qwen3.5 官方发布文章与 arXiv 论文使用明确区分的来源契约：官方文章的 arXiv ID 为空，元信息与列表标明“官方文章”，原文入口标为 Qwen，并链接到原始发布文章。页面不会把博客称为 arXiv 论文。
