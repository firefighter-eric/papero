# Papero 折页 p 标识

用户选定的第一个 logo 方案，使用 Image Gen 生成独立透明图标后导出。

- `papero-mark.png`：256 × 256 透明 PNG，页面通过 alpha 蒙版沿用阅读主题的品牌色。
- 根目录的 `favicon-16.png`、`favicon-32.png`、`favicon.ico`：同一标识的浏览器图标，使用浅米色背景以兼顾深浅标签栏。
- `apple-touch-icon.png`：180 × 180、不透明浅米色背景，保留主屏幕图标安全边距。

生成描述：粗几何 p，圆角碗部、透明内孔、短而厚的左下竖干，以及右上角的纸张斜切角；保留选定方案的轮廓，独立透明背景，无文字。导出仅裁去透明边距、缩放并为网站图标添加背景；不以代码重新绘制标识。

原始生成稿与选定方案预览保存在被 Git 忽略的 `.cache/brand/`，线上只需上述小尺寸导出资源。
